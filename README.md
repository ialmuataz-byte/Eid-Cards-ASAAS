# استوديو بطاقات العيد · أساس

موقع عربي بسيط ومتجاوب لتصميم بطاقات تهنئة العيد للموظفين، بأسلوب تحريري نظيف مستوحى من ثمانية.

## المحتويات

```
eid_site/
├── index.html          # الصفحة الرئيسية للموقع (تحتوي على كل شيء)
└── assets/
    ├── logo.png        # شعار أساس (شفاف)
    ├── template1.jpg   # تصميم: الحصن
    ├── template2.jpg   # تصميم: الرزحة العمانية
    ├── template3.jpg   # تصميم: قطف الورد
    ├── template4.jpg   # تصميم: تراث الورد
    └── template5.jpg   # تصميم: العيدية
```

## التشغيل محلياً

افتح المجلد في الطرفية وشغّل خادماً بسيطاً (مطلوب لتحميل صور القوالب):

```bash
cd eid_site
python3 -m http.server 8000
```

ثم افتح في المتصفح: http://localhost:8000

> ملاحظة: لا يكفي فتح `index.html` مباشرة لأن المتصفح يمنع الوصول لملفات الصور من نظام الملفات. أيّ خادم محلي بسيط يحلّ المشكلة.

## النشر

يمكن استضافة الموقع على أي خدمة استضافة ساكنة:
- **Netlify / Vercel / Cloudflare Pages**: اسحب المجلد كاملاً.
- **GitHub Pages**: ارفع المجلد إلى مستودع وفعّل Pages.
- **خادم داخلي للشركة**: ضع المجلد في أي مجلد عام للخادم.

## التخصيص

- **إضافة تصميم جديد**: ضع الصورة في `assets/` ثم أضف عنصراً جديداً إلى مصفوفة `TEMPLATES` في `index.html`.
- **تغيير الألوان**: في رأس `<style>` ضمن متغيرات `:root` (مثلاً `--gold` للون الذهبي).
- **تعديل نص التهنئة**: ابحث عن `عيدكم مبارك` و `كل عام وأنتم بخير` داخل دالة `drawCard()` في السكربت.

## الخصائص

- ✅ واجهة عربية كاملة من اليمين إلى اليسار
- ✅ متجاوبة (الجوال والحاسوب)
- ✅ معاينة حية فورية للبطاقة
- ✅ تحميل البطاقة كصورة PNG بدقة 1080×1350
- ✅ خطوط `Amiri` و `Tajawal` من Google Fonts
- ✅ لا يحتاج أي خادم خلفي أو قاعدة بيانات
